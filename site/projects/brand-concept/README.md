# Aether Spatial Optics // Fictional Brand Identity Concept

A comprehensive fictional brand identity and spatial design system for a conceptual optical physics hardware laboratory.

> **Disclaimer:** Concept, not a real client. Self-initiated speculative design project.

## What It Is
An identity system exploring the intersection of precision spatial hardware, optical lens calibration, and minimalist brutalism. The project presents an SVG geometric focal mark, a multi-tier design token system, and three applied real-world mockups (an architectural exhibition poster, an embedded device controller UI, and an industrial packaging flat).

## Key Features
- **Brand Shift Engine:** Live palette switcher switching across 3 chromatic themes (*Titanium Void*, *Solar Quartz*, and *Cyber Flora*) via CSS custom property mutation.
- **Applied Mockups:**
  1. *Exhibition Screen Poster:* Strict typographic grid alignment with high-contrast hierarchical hierarchy.
  2. *Controller App Screen:* Dark-mode hardware telemetry with an animated rotating optical aperture ring and depth controls.
  3. *Packaging Flat:* Unfolded die-cut box geometry with barcode, serial numbering, and QA stampings.
- **Under the Hood:** Interactive 40px construction grid toggle and token contrast ratio specification table.

## How To Run
Open `index.html` in any modern web browser or serve with `npx serve`.
