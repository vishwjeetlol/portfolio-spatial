Elastic Collision Impulse Resolution

vec3 delta = b2.pos - b1.pos;
float dist = length(delta);
if (dist < (b1.radius + b2.radius)) {
  vec3 normal = delta / dist;
  vec3 relVel = b2.vel - b1.vel;
  float velAlongNormal = dot(relVel, normal);
  if (velAlongNormal < 0.0) {
    float j = -(1.0 + restitution) * velAlongNormal / (b1.invMass + b2.invMass);
    vec3 impulse = normal * j;
    b1.vel -= impulse * b1.invMass;
    b2.vel += impulse * b2.invMass;
  }
}

Raycast Spring Tether Mechanics

When pointer presses any mesh:
1. Raycaster unprojects screen coordinate into 3D world plane
2. Spring tension force: F = -stiffness * (object.pos - rayTarget)
3. Angular torque applied proportional to cross product: τ = r × F
4. Release fling vector inherits instantaneous pointer momentum
