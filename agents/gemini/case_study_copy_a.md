# Case Study Copy Variant A (Gemini Perspective: Spatial & Craft Focus)

## Project 1: The Museum of Three.js
- **Headline:** A 22-Exhibit Procedural Virtual Pavilion Built on WebGL & Vite
- **Executive Narrative:** Built to push the boundaries of browser-based real-time graphics, The Museum of Three.js orchestrates 22 interactive exhibits spanning custom GPU vertex curl shaders, procedural mesh generation, and dynamic particle compute. Every exhibit adheres to strict Y2K brutalist color theory while maintaining a locked 60 FPS across desktop viewports.
- **Under the Hood:** Custom WebGL spotlight pooling reduces active GPU render overhead from 22 sources to 2 dynamic track lights following the visitor's focus coordinates.

## Project 2: Tata Truck Cabin Simulator & The Bazaar
- **Headline:** First-Person Interactive Cultural Simulator Powered by Web Audio
- **Executive Narrative:** Transporting the tactile soul of Indian transport folklore into interactive web software, this dual-experience couples an authentic Tata 1613 SE cabin simulator with a panoramic draggable bazaar canvas. Users rev procedural engines, trigger synthesized horns, and change road weather states.
- **Under the Hood:** Synthesis routines calculate frequency modulation curves directly through the Web Audio API without pre-recorded MP3 bloat.
