# Design System

## Overview
A maximalist, culturally unapologetic design language fusing Indian street aesthetics, truck art vernacular signage, and bazaar sensory richness with high-precision computer graphics (WebGL, GLSL, Web Audio API DSP).

## Colors
- **Saffron Orange (`#ff8400`):** Core energetic brand beacon, used for primary actions, pulse markers, and key interactive highlights.
- **Rani Pink / Gulabi (`#ff007f`):** High-saturation cultural accent for gradients, postal stamps, and bold CTAs.
- **Electric Peacock Cyan (`#00f0ff`):** Cybernetic spatial accent for tech tags, shader indicators, and secondary controls.
- **Haldi Gold (`#ffd700`):** Truck art ornamental borders, postal stamps, and gold typography glyphs (`✦ ❖ ✦`).
- **Base Midnight (`#090a0d` / `#111318`):** Deep, warm night background with subtle radial color glows.

## Typography
- **Display Headings:** Ultra-bold sans-serif (`-apple-system`, `SF Pro Display`) set with tight negative letter-spacing (`-0.03em`) and high-impact hierarchy.
- **Code & Vernacular Telemetry:** Monospace (`SF Mono`, `Menlo`) for pin codes, tech badges, postmark stamps, and frame budgets.
- **Editorial Contrast:** Occasional serif accents (`Georgia`) for philosophic counterpoints.

## Layout
- **Full-Bleed Hero Stage:** 92vh viewport for the kinetic 3D Gyroscope centerpiece.
- **3D Spatial Coverplay:** 1100px perspective carousel with revolving perforated postal stamps and floor mirror reflection.
- **Exhibition Portals:** Single-column wide-bleed narrative cards with 3D pointer tilt.
- **Experimental Systems Grid:** 3-column responsive card matrix.
- **Floating Action Dock:** Persistent bottom pill navigation.

## Elevation & Depth
- **Spatial 3D Transforms:** `perspective: 1100px`, `transform-style: preserve-3d` for the Cover Flow and Gyroscope.
- **Tonal Layering:** Deep black-violet surface backgrounds with 1px border highlights (`rgba(255, 215, 0, 0.25)`).
- **Floor Reflections:** CSS `-webkit-box-reflect` mirroring stamp cards in 3D perspective.

## Shapes
- **Perforated Stamp Edges:** Radial-gradient cutouts creating authentic serrated postage stamp borders.
- **Hazard Chevron Tape:** Repeating 45-degree yellow and dark hazard bands.
- **Pill Badges:** Capsule-shaped chips for status indicators and audio toggles.

## Components
- **3D Kinetic Hero Gyroscope:** WebGL titanium-ring scene with optical refractive glass core.
- **Apple Coverplay Carousel:** 3D card slider with drag, wheel, keyboard, and click controls.
- **Postal Stamp Photo Booth:** Live webcam selfie / file upload canvas filter and postmark cancellation stamping engine.
- **Procedural Web Audio Engine:** Zero audio files; synthetic truck horn, sitar plucked harmonics, and mechanical stamp thuds.
- **Interactive CV Drawer:** Embedded responsive modal with 1-click A4 PDF download.

## Do's and Don'ts
- **DO** keep frame rates locked at 60 FPS (16.6ms frame budget).
- **DO** use authentic postal philately details (pincodes, postmarks, franking marks).
- **DO** maintain sub-second static production build times.
- **DON'T** use generic, unstyled corporate gray cards.
- **DON'T** use empty placeholder `<img>` tags or broken image references.
- **DON'T** sacrifice accessibility contrast on interactive buttons.
